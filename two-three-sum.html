双指针复习卡片 · Two Pointers

核心思想 相向双指针是什么？ ▶
前提条件

数组必须是有序的，双指针才能work。

核心原理
  • 左指针 L 从最小值出发，右指针 R 从最大值出发
  • 每次移动都是有根据的排除，不是盲目猜测
  • s > target → R 太大，右指针左移
  • s < target → L 太小，左指针右移

为什么能排除？因为数组有序，min + max > target，说明 max 右边的数加上任何数都只会更大，max 可以永久排除。

时间复杂度

O(n)，远优于暴力枚举的 O(n²)

LeetCode 167 · Two Sum II
167 题目思路 ▶
题目

已排序数组，找两个数加起来等于 target，返回 1-indexed 的下标。

解法
  • left = 0，right = len(numbers) - 1
  • s = numbers[left] + numbers[right]
  • s == target → break，返回 [left+1, right+1]
  • s > target → right -= 1
  • s < target → left += 1

注意：1-indexed 是返回的下标从1开始，数组本身在Python里还是0-indexed，所以返回时要 +1。

踩坑 167 · 我犯过的错误 ▶
错误 1：s 定义在循环外
  • s 必须在 while 循环内、if 判断之前更新
  • 否则每次循环用的是旧的 s，不反映当前 left/right
错误 2：用两个 if 而不是 if/elif
  • s > target 和 s < target 只会成立一个
  • 用 elif 更严谨，避免多余判断
# ❌ 错误写法
while left < right:
    if s == target: break
    if s > target: right -= 1
    if s < target: left += 1
    s = numbers[left] + numbers[right]  # s 在最后更新

# ✅ 正确写法
while left < right:
    s = numbers[left] + numbers[right]  # s 在最前更新
    if s == target: break
    elif s > target: right -= 1
    elif s < target: left += 1
LeetCode 15 · 3Sum
15 题目思路 ▶
核心转化

固定一个数 x = nums[i]，把问题转化为：在剩余数组里找两个数加起来等于 -x。

为什么 range(n-2)

需要三个不同位置 i < j < k，i 最大是 n-3，所以用 range(n-2)。

为什么 i < j < k

数组排序后规定 i < j < k，保证每个 triplet 只被找到一次，避免重复答案。

剪枝优化
  • x + nums[i+1] + nums[i+2] > 0 → break（后面的 x 只会更大，不可能找到答案）
  • x + nums[n-2] + nums[n-1] < 0 → continue（当前 x 太小，换下一个）
15 去重逻辑 ▶
三处去重
  • 跳过重复的 x：if i > 0 and x == nums[i-1]: continue
  • 找到答案后跳过重复的 j：j+=1，while j<k and nums[j]==nums[j-1]: j+=1
  • 找到答案后跳过重复的 k：k-=1，while k>j and nums[k]==nums[k+1]: k-=1

关键：先移动一步，再用 while 跳过重复。边界条件要写在 while 的左边（Python 短路求值）。

15 完整代码 ▶ 
def threeSum(nums):
    nums.sort()
    ans = []
    n = len(nums)
    for i in range(n-2):
        x = nums[i]
        if i > 0 and x == nums[i-1]:
            continue                      # 跳过重复 x
        if x + nums[i+1] + nums[i+2] > 0:
            break                         # 剪枝
        if x + nums[n-2] + nums[n-1] < 0:
            continue                      # 剪枝
        j, k = i + 1, n - 1
        while j < k:
            s = x + nums[j] + nums[k]
            if s == 0:
                ans.append([x, nums[j], nums[k]])
                j += 1
                while j < k and nums[j] == nums[j-1]:
                    j += 1                 # 跳过重复 j
                k -= 1
                while k > j and nums[k] == nums[k+1]:
                    k -= 1                 # 跳过重复 k
            elif s > 0:
                k -= 1
            elif s < 0:
                j += 1
    return ans
踩坑 如何读懂 IndexError ▶
错误信息结构
  • 错误类型：IndexError: list index out of range → 用了不存在的 index
  • 调用栈：从下往上读，找到你自己代码里的那一行
  • 只需关注最后一个 "in threeSum" 那行
边界保护原则
  • 内层 while 不受外层 while 保护，必须自己加边界条件
  • 边界条件要写在 and 的左边（短路求值，左边False直接跳过右边）
# ❌ 危险：边界在右边，可能先越界再判断
while nums[j] == nums[j-1] and j < n:

# ✅ 安全：边界在左边，先检查再访问
while j < k and nums[j] == nums[j-1]:
